# Security policy

Read [the threat model and boundaries](docs/security.md) before enabling Internet access. This release is experimental and offers no uptime/security guarantee.

Use this repository's private vulnerability reporting feature if enabled. Otherwise request a confidential contact from the maintainer without posting secrets or exploit details in an Issue. Supply the affected version, minimal redacted reproduction and expected boundary. Do not attach raw runtime databases, authentication logs, headers, private user data or credentials.

Only the latest documented alpha is maintained on a best-effort basis. Do not use real hardware or production data for reproduction.
